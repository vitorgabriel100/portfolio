Projeto corporativo · Automação · Integrações

Monitoramento automatizado de integrações

Acompanhamento recorrente de integrações operacionais para identificar anomalias e apoiar o registro e tratamento de incidentes. O projeto combina consultas a dados corporativos, regras de verificação e integração com uma plataforma de chamados, reduzindo a dependência de verificações manuais.

Problema Verificações periódicas de sistemas exigiam acompanhamento operacional
Solução Verificação a cada 5 minutos e integração com a API do Movidesk
Contexto Solução corporativa apresentada sem infraestrutura ou dados internos
PythonOracleSQL APIs RESTAutomação

Estudo de caso descritivo: por confidencialidade, o código, o painel interno e dados de clientes não são disponibilizados publicamente. Não atribuo a este projeto ganhos percentuais que não foram medidos.

Machine Learning · Forecasting · Avaliação de modelos

Service Desk Demand Forecast

Pipeline para prever o volume diário de chamados de suporte. Comparei métodos de referência sazonais com Random Forest, usando variáveis temporais e avaliação em um período futuro separado do treinamento.

Dados Conjunto simulado de chamados, com avaliação nos últimos 28 dias
Resultado na avaliação Random Forest: MAE 4,48 · RMSE 6,44
Referência comparada Baseline híbrido: MAE 21,42 no mesmo estudo
PythonPandasScikit-learn Random ForestSéries temporais

Os resultados descrevem o experimento com dados simulados; não representam desempenho comprovado em produção ou em dados reais de clientes.
